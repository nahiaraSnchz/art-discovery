# Datos y fuentes

## 1. Entidades principales

| Entidad | Información mínima |
|---|---|
| Obra | Identificador, título, autor, fecha o periodo, movimiento o estilo, imagen y fuente. |
| Paleta | Obra asociada, colores dominantes, proporción relativa, método de extracción y fecha de procesamiento. |
| Entidad artística | Artista, movimiento o época, descripción, intervalo temporal, obras relacionadas y fuentes documentales. |
| Reto | Tipo de identificación, evidencia cromática, opciones, respuesta correcta, explicación y dificultad. |
| Sesión | Retos realizados, respuestas, puntuación y fecha de inicio. |

## 2. Fuentes previstas

La colección podrá utilizar datos de The Met, Rijksmuseum, Wikidata u otras fuentes públicas compatibles con el proyecto. Cada registro deberá conservar la referencia de origen y las condiciones de uso aplicables.

## 3. Calidad de los datos

- Las fechas podrán representarse como años, intervalos o periodos aproximados.
- Una obra sin imagen válida no deberá incluirse en un reto que dependa de su paleta.
- Las explicaciones deberán distinguir hechos documentados de interpretaciones.
- La colección deberá contener suficientes obras para que una línea temporal sea significativa.

## 4. Tratamiento cromático

Las paletas podrán calcularse mediante agrupamiento de colores, cuantización, histogramas o una biblioteca especializada. La técnica concreta queda pendiente de decisión y deberá registrarse junto con la paleta resultante.
