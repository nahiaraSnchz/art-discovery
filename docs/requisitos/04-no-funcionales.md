# Requisitos no funcionales

Estos requisitos describen las condiciones de calidad del MVP.

| Identificador | Categoría | Requisito | Prioridad |
|---|---|---|:---:|
| RNF-01 | Usabilidad | El usuario podrá iniciar un reto sin instrucciones extensas. | Alta |
| RNF-02 | Accesibilidad | El color no será el único medio de transmitir información; se acompañará de texto, etiquetas, fechas o patrones. | Alta |
| RNF-03 | Rendimiento | Las paletas previamente procesadas se mostrarán sin esperas perceptibles en el flujo normal. | Alta |
| RNF-04 | Compatibilidad | La aplicación funcionará en navegadores modernos de escritorio y móvil. | Media |
| RNF-05 | Trazabilidad | Cada obra, metadato y explicación estará asociado a una fuente. | Alta |
| RNF-06 | Mantenibilidad | Los datos, la lógica del juego y las visualizaciones estarán desacoplados. | Media |
| RNF-07 | Privacidad | El MVP no requerirá datos personales ni autenticación. | Alta |
| RNF-08 | Licencias | Las imágenes y los metadatos se utilizarán respetando sus condiciones de uso y atribución. | Alta |
| RNF-09 | Fiabilidad | Las obras sin imagen, con fechas incompletas o sin paleta calculable no interrumpirán la partida. | Alta |
