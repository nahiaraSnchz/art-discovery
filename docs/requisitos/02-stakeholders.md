# Stakeholders y usuarios

## 1. Usuario jugador

Persona interesada en arte, cultura visual o juegos de conocimiento. Utiliza la aplicación para:

- Resolver retos de identificación.
- Aprender sobre artistas, movimientos y periodos.
- Comparar el uso del color entre obras o autores.
- Consultar información visual de forma sencilla.

## 2. Equipo de contenido

Rol responsable de seleccionar y revisar:

- Obras y metadatos.
- Paletas cromáticas.
- Artistas, movimientos y periodos.
- Preguntas, respuestas y explicaciones.

Este rol se contempla inicialmente como una actividad de preparación de datos, no como una interfaz de administración incluida en el MVP.

## 3. Fuentes externas

Museos, catálogos y servicios de datos públicos proporcionan imágenes y metadatos. Sus condiciones de uso, atribución y límites de consulta deberán respetarse.

## 4. Exclusiones iniciales

El MVP no requiere cuentas de usuario, administradores autenticados, perfiles, clasificación global ni almacenamiento remoto del progreso.
