# Requisitos Funcionales

| Identificador | Nombre | Descripción | Prioridad |
| :--- | :--- | :--- | :---: |
| **RF-01** | Procesamiento cromático | El sistema debe extraer las $N$ bandas de color dominantes de cada obra pictórica. | Alta |
| **RF-02** | Línea temporal | Debe renderizar cronológicamente la evolución de paletas de un artista o movimiento. | Alta |
| **RF-03** | Modo adivinanza | La aplicación ocultará la imagen original y propondrá 4 opciones (autores o épocas) al usuario. | Alta |
| **RF-04** | Revelación cultural | Tras la selección, se muestra la obra real, su ficha técnica y una breve explicación sobre sus pigmentos. | Media |
| **RF-05** | Puntuación y rachas | Registro local del progreso del usuario (aciertos consecutivos, tiempo por ronda). | Baja |
