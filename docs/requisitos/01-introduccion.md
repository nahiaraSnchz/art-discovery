# Introducción y contexto

## 1. Contexto

Art Discovery es una aplicación web orientada al aprendizaje y la exploración del arte mediante el análisis del color. El sistema transforma colecciones de obras en paletas y líneas temporales para que el usuario pueda inferir un artista, movimiento o periodo.

La propuesta combina una experiencia lúdica con una explicación cultural posterior. El objetivo no es certificar autorías, sino mostrar cómo los patrones cromáticos pueden servir como punto de partida para descubrir trayectorias y contextos artísticos.

## 2. Problema que se aborda

La consulta tradicional de catálogos de arte suele separar la información visual de la explicación histórica. El sistema propone unir ambas dimensiones mediante retos breves en los que la progresión de colores constituye la principal pista.

## 3. Objetivos de la aplicación

- Presentar información artística de forma visual e interactiva.
- Ayudar a reconocer diferencias cromáticas entre autores, estilos y épocas.
- Convertir el análisis de paletas en una actividad de descubrimiento.
- Proporcionar contexto verificable después de cada respuesta.
