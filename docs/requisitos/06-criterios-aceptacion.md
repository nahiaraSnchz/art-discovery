# Criterios de aceptación del MVP

El MVP se considerará aceptable cuando se cumplan los siguientes criterios:

| ID | Criterio |
|---|---|
| CA-01 | El usuario puede iniciar una partida desde la pantalla principal. |
| CA-02 | Se muestra al menos un reto con una visualización cromática comprensible. |
| CA-03 | El usuario puede elegir una respuesta entre varias opciones. |
| CA-04 | El sistema indica correctamente si la respuesta es acertada. |
| CA-05 | Se muestra la solución y una explicación asociada a obras reales. |
| CA-06 | La explicación incluye la evolución temporal del color. |
| CA-07 | La puntuación de la sesión se actualiza correctamente cuando está habilitada. |
| CA-08 | Las fuentes de las obras y de los datos son visibles. |
| CA-09 | La interfaz sigue siendo usable cuando existen colores similares o información temporal incompleta. |
| CA-10 | Una obra sin datos suficientes no bloquea la partida ni se utiliza como evidencia inválida. |

## Relación con los requisitos

Estos criterios verifican principalmente los requisitos funcionales RF-01 a RF-13 y los requisitos de calidad RNF-01, RNF-02, RNF-05 y RNF-09. No añaden funcionalidades nuevas; sirven para comprobar la aceptación del alcance definido.
